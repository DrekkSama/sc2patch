# SC2 5.0.15 Complete Change List (base + hotfix)

## Sources
- Base 5.0.15: https://news.blizzard.com/en-us/article/24225313/starcraft-ii-5-0-15-patch-notes
- 5.0.15 Hotfix: https://news.blizzard.com/en-us/article/24240447/starcraft-ii-5-0-15-hotfix-patch-notes
- Verified against SC2 Editor Balance Data Export (SC2 5.0.16 install, which includes 5.0.15 changes)

## ZERG
### Spire
- Cost: 200/200 → 150/150 ✅ (Editor: cost=150/150)
- Build time: 71s → 66s ✅ (Editor: time=92.4 frames ≈ 66s)

### Centrifugal Hooks (Baneling upgrade)
- +5 HP bonus to Banelings restored (was removed in earlier patch)
- NOTE: HP bonus is in upgrade effect data, not in per-unit Editor export

### Microbial Shroud (Infestor ability)
- Reduces ranged attacks by 50% damage (new mechanic)
- Effect no longer persists after unit leaves the shroud
- Cost: 75 → 100 energy
- Now requires an upgrade again (150/150)
- NOTE: These are behavior/ability changes not fully visible in per-unit export

## PROTOSS
### Energy Recharge (Nexus ability)
- Grant reduced: 100 → 50 energy
- Cooldown reduced: 60s → 45s
- NOTE: Not visible in per-unit Editor export (Nexus ability)

### Mothership
- Movement speed: 2.83 → 2.25 ✅ (Editor: speed=1.6054, which is 2.25 in game units)

### Psionic Storm (High Templar)
- Damage: 80 over 3s → 140 over 6s (hotfixed to 110 over 6s) 
- Radius: 1.5 → 2
- Range: 9 → 8
- NOTE: Psi Storm in Editor shows energy=75, cooldown=2, range=8 ✅

### Dark Templar
- Blink attack delay: 0.75 → 0.25
- NOTE: Delay is in weapon/behavior data, not in per-unit export. DT Blink cooldown=20 ✅

### Observer
- Surveillance mode now reveals Observers
- Surveillance mode vision: 13.75 → 15
- NOTE: Observer has ObserverMorphtoObserverSiege ability, sightRadius=11 (base), siege vision in behavior data

### Purification (Oracle? or Mothership?)
- Cooldown: 21.4s → 17s
- NOTE: Not clearly identified in Editor export — may be on a different unit

### Stasis Ward (Oracle buildable)
- Duration: 170s → 90s
- NOTE: Duration in behavior data, not in per-unit export

## TERRAN
### Siege Tank
- Can no longer be abducted when in siege mode
- NOTE: This is a validator/behavior change on the Viper's Abduct ability

### Viking
- Cost: 150/75 → 125/75 ✅ (Editor: cost=125/75)
- NOTE: VikingFighter.xml confirms minerals=125, vespene=75

### Drilling Claws (upgrade)
- Effectiveness: 1.07 → 0.71s (faster)
- NOTE: In upgrade effect data, not in per-unit export

### Hyperflight Rotors (upgrade)
- Research time: 100s → 79s
- NOTE: In upgrade data, not in per-unit export

### Liberator
- Sight: 10 → 9 ✅ (Editor: sightRadius=9)

### Ghost
- Supply: 3 → 2 ✅ (Editor: supply=-2, also confirmed in 5.0.16)
- Now has Light attribute ✅ (Editor: attributes include "Light")
- 5.0.15 Hotfix: HP increased from 100 → 125 (restored)
  - NOTE: 5.0.16 later changed HP back to 100

- Broodlord speed: 2.62 → 2.24 ✅ (Editor: speed=1.6015 ≈ 2.24 in game units)
